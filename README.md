# Uso e Consumo

Sistema interno para gerenciamento de requisições de materiais de escritório.

## Estrutura

```
uso-consumo/
├── web/   → Frontend (Next.js + TypeScript + Tailwind)
└── api/   → Backend  (Node.js + Express + TypeScript)
```

## Como rodar

### Frontend
```bash
cd web
npm run dev
```

### Backend
```bash
cd api
npm run dev
```
